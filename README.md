# Indian Stock Market Data & Deep Analysis Pipeline

Production-quality automated daily Indian stock market data ingestion, technical & fundamental analysis, historical pattern matching, probabilistic prediction, backtesting, and daily report generation system.

## Features & Capabilities

1. **Configurable Universe**: Tracks NIFTY 50, sector indices (Bank, IT, Auto, Pharma, FMCG, Metal, Realty, Energy, Fin Services), and individual equities configured via `config/stocks.json`.
2. **Robust Data Ingestion**: Modular `MarketDataProvider` abstraction (Yahoo Finance with retries/rate-limiting and Mock fallback).
3. **Data Quality & Validation**: OHLC validation, detection of negative prices, volume anomalies, splits, missing dates, and JSON quality reporting (`data/quality/YYYY-MM-DD.json`).
4. **Comprehensive Technical Analysis**: SMA (5 to 200), EMA (9 to 200), RSI 14, Stoch RSI, MACD, ATR 14, Volatility Regime, OBV, A/D, 52-week High/Low distances, Pivot Points, Breakouts, and Golden/Death crosses.
5. **Market Regime Classification**: Rule-based transparent environment classification (Strong Bullish to Strong Bearish) based on NIFTY moving averages and market breadth.
6. **Sector & Composite Scoring**: Sector rankings by momentum and relative strength vs NIFTY; 0-100 composite stock scoring.
7. **Empirical Historical Analogues**: Finds past Euclidean pattern matches (RSI, Volatility, Moving Average distances) and calculates 1D to 20D empirical forward probability statistics.
8. **Machine Learning & Signal Engine**: Strict time-series walk-forward validation (no look-ahead bias or random temporal shuffling) generating probabilistic directional signals (1D to 20D) with confidence scores.
9. **Realistic Backtesting Engine**: Evaluates signal strategy with transaction costs, slippage, and position limits (CAGR, Sharpe Ratio, Max Drawdown).
10. **Daily Markdown & Machine-Readable Reports**: Outputs `reports/daily/YYYY-MM-DD.md` and `data/analysis/daily/YYYY-MM-DD.json`.
11. **GitHub Actions Workflow**: Automated daily execution scheduled on Indian trading days (`.github/workflows/daily-market-analysis.yml`).

## System Architecture

```
src/
├── ingestion/       # MarketDataProvider interface, YahooFinance & Mock implementations
├── validation/      # DataValidator & quality report generator
├── storage/         # StorageManager (Parquet, JSON, CSV)
├── indicators/      # TechnicalIndicators engine
├── market/          # MarketRegimeAnalyzer
├── sectors/         # SectorAnalyzer
├── fundamentals/    # FundamentalAnalyzer
├── scoring/         # StockScorer composite 0-100 engine
├── features/        # FeatureEngineer (leakage-free target generation)
├── patterns/        # HistoricalAnalogueAnalyzer
├── modeling/        # PredictionModule (Walk-forward ML baseline)
├── backtesting/     # BacktestEngine
├── reporting/       # ReportGenerator (Markdown & JSON)
├── utils/           # GitIntegration & helpers
└── pipeline/        # DailyPipeline orchestrator
```

For detailed architectural breakdown, see [docs/architecture.md](docs/architecture.md).

## Setup & Running Locally

### Prerequisites
- Python 3.12+

### Installation
```bash
pip install -r requirements.txt # or: pip install yfinance pandas numpy scikit-learn pyarrow pytest requests
```

### Run Daily Pipeline
```bash
# Run for a specific trading date
PYTHONPATH=. python3 src/pipeline/daily_pipeline.py --date 2026-03-30 --force

# Run with automated Git commit
PYTHONPATH=. python3 src/pipeline/daily_pipeline.py --date 2026-03-30 --force --auto-commit
```

### Run Automated Tests
```bash
PYTHONPATH=. pytest tests/
```
